# Gates releases

Installable builds of **Gates**, a calm Android launcher that puts a pause only where you ask for one.

Download the APK from the [latest release](https://github.com/pridgey/gates-releases/releases/latest),
install it, and set Gates as your default home app. After that, Gates updates itself from here
(Gates app → Settings → Updates).

Releases are published automatically from the private source repository.
